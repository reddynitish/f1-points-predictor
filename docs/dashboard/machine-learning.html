How the prediction works

It learns a pattern from past races, then uses qualifying position to estimate each driver’s chance of scoring.

What does the percentage mean?

90% chance of points

The model thinks scoring at least 1 race point is likely. It can still be wrong.

It estimates whether a driver will score, rather than how many points they will earn. Sprint points are excluded.

How we get that number

  1. Learn from earlier races.For each driver, look at qualifying position and whether they later scored race points.
  2. Find the pattern.The model learns how the chance of scoring changes with qualifying position.
  3. Read the new qualifying results.Use each driver’s position to calculate a percentage. Sunday’s result is still unknown.
  4. Save it, then check it.Keep the prediction before the race starts. After the race, compare it with who actually scored.

Why keep the model simple?

We also tested driver and team history, practice, weather and other information. Those models did not show a clear improvement over qualifying position alone.

So qualifying position remains the main input.

That is a useful result: more information does not automatically make a better prediction.

Crashes, retirements and unexpected race events can change the result. A high chance is not a guarantee.

Where does the data come from?

Past race data comes from Jolpica, a free F1 data service. For Singapore’s live forecast, api-anything reads qualifying positions from F1’s official website.

Qualifying position can differ from Sunday’s starting grid. We keep them separate. If a qualifying position is unknown, the dashboard flags it.

Model details and saved evidence

The model, in one sentence

The main model uses logistic regression: it learns a curve that turns qualifying position into a probability. Reports call this model B1. A separate model, M1, adds driver and team history for comparison.

How we kept the test fair

  • Train on earlier races and test on later ones.
  • Keep every driver from a race in the same test group.
  • Keep the new race’s result out of its prediction.
  • Choose model settings before opening the final test results.
  • Keep saved forecasts unchanged after results arrive.

2025 and 2026 rounds 1–16 have already been used for testing. A new model needs fresh, untouched race results.
